# 函数画布

图像优先的函数探索网页原型。第一阶段验证：输入函数、在画布中查看图像，并以可追溯的平移和缩放变换直接操作图像。

## 当前能力

- 绘制多个实变量显式函数，支持多项式、有理式、`sin`、`cos`、`tan`、`sqrt`、`abs`、`exp`、`log`、`pi` 与 `e`。
- 鼠标和触控画布平移；手机端以底部表达式抽屉适配窄屏。
- 数学约束模式：双击曲线或触屏长按创建白点，拖动白点后使用较宽的数学影响核。
- 棉线张力模式：操作同一条曲线和同一批白点，通过纵向质点链松弛传播位移，影响范围比数学约束模式更窄。
- 两种模式都只能通过白点改变曲线，白点只能上下移动，以保持单值函数。
- 连续拖拽始终以上一次结果为原型，不会在下一次操作时恢复到初始函数。
- 鼠标悬停显示当前点坐标与导数；点击曲线或白点可固定读数并显示切线。
- 一键创建数值导函数图像。

## 本地运行

```bash
npm install
npm run dev
```

## 检查

```bash
npm run lint
npm run build
```
