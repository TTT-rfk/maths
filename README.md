# 函数画布

图像优先的函数探索网页原型。第一阶段验证：输入函数、在画布中查看图像，并以可追溯的平移和缩放变换直接操作图像。

## 当前能力

- 绘制多个实变量显式函数，支持多项式、有理式、`sin`、`cos`、`tan`、`sqrt`、`abs`、`exp`、`log`、`pi` 与 `e`。
- 鼠标和触控画布平移；手机端以底部表达式抽屉适配窄屏。
- 数学约束模式：双击曲线或触屏长按创建白点，只有拖动白点才会改变数学图像与表达式。
- 自由棉线模式：直接拖动独立的弹性采样线，位移沿两侧局部传播；支持可拖动、可删除的棉线固定点。
- 连续拖拽始终以上一次结果为原型，不会在下一次操作时恢复到初始函数。
- 两种模式的状态、命中检测和控制点完全隔离，并可一键恢复原函数形状。
- 一键创建数值导函数图像。

## 本地运行

```bash
npm install
npm run dev
```

## 检查

```bash
npm run lint
npm run build
```
